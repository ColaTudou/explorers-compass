🎯 关键决策

  • 技术形态：纯前端静态站（HTML+CSS+原生 JS），数据存 localStorage。零安装、零部署，双击即用。
  • 脚本加载：用传统 <script> 而非 ES Module，避免 file:// 下的 CORS 限制。
  • 双人模拟：单机版通过「身份切换」模拟 A/B 双方，完整保留双面叙事与双方确认逻辑。
  • 文案生成：PRD 要求接 LLM，本地版用模板引擎实现同风格输出，替换 Recommend.writeCopy() 即可接真模型。
  • 标签黑名单软过滤：一条低分旅程常带 6 个通用标签，全量剔除会清空候选池；改为候选 ≥3 条时才生效。
  • 图片压缩降级：1080px/85% → 800px/68%，避免超出 localStorage ~5MB 配额。
  • AI 唤醒用规则引擎：PRD 要求接大模型出题，本地版用分分类问题库 + 模板合成， 离线可控。替换 Awaken.bank() / Awaken.compose() 即可接真模型。
  • 考古复苏只读商户名+日期：解析时主动过滤余额宝/花呗/转账/红包，金额不进任何字段（PRD 4.1 数据安全）。
  • LLM 只做渐进增强：界面先用本地模板/题库秒出，LLM 结果到了才替换； 失败、超时（15s）、JSON 格式不对一律静默回退。所以不配密钥也完全能用。
  • LLM 只认 OpenAI 兼容协议：一个端点字段就能在 DeepSeek / 通义 / 智谱 / Moonshot / Ollama / 自建代理之间切换，不用改代码。
  • 天气选 Open-Meteo：免费、无密钥、允许跨域，是纯前端唯一能直接调的正规天气源。
  • 通知只在页面开着时触发：无服务端就没有后台推送，这是纯前端的硬边界， 不是偷懒。已用 PWA 安装 + 首页横幅做补偿，README 里写明了。
  • 深色不是反相：做成「夜间暖纸」（#1E1712 深棕底 + #F2E7DA 暖米字）， 情绪色也整体降亮，保住纸感温度。
  • Phase 3 入口放在「我的 → 更多功能」：星光集 / 待办 / 胶囊 / 报告 都没占底部 Tab，因为 PRD 5.2.2 明确规定了 5 个 Tab。
  • 节日只收公历：春节 / 七夕 / 中秋是农历，公历推算不了，README 里注明未收录。
  • PWA 必须 http/https：file:// 下浏览器禁用 SW 与安装能力， 所以把 启动本地服务.bat 提升为推荐方式。
  • IndexedDB 兜底扩张：内存永远持全量 dataURL，持久层用 JSON.stringify replacer 把超 48KB 的图换成 @@idb:key@@ 占位符，本体放 IndexedDB。 视图 / 导出 / 双面叙事零改动。file:// 与隐私模式下若 IDB 不可用自动回退老路。
  • 同内容图片自动去重：keyOf 用 djb2 + 长度前缀，相同图片天然共享一个 IDB key。 同一张图被多处引用（封面+数组、合并双方）只存一次。
  • 第三方表格走智能列映射：嗅探表头关键词（名称/时间/分类/图片/金额）， 金额列只用来跳过、绝不落地；无表头走启发式最长文本。无外链图下载（离线优先、不防盗链）。
  • PWA 真机三件套：相对路径 start_url（任意子目录都能装）、PNG 192/512 图标 （Chromium 安装条件，iOS 触屏图标）、SW v4 预缓存（含 PNG 4 张）。 三个坑全踩过，少秋手机能直接装。

⚠️ 待办与风险

  • 风险LLM 密钥明文存本地：自用可接受，共享电脑别用。 缓解：端点可换成自建代理，代码不用改。
  • 风险三类能力依赖 http：摄像头、通知、PWA 在 file:// 下不可用。缓解：一键本地服务脚本 + CloudStudio https 链接 + 能力自动降级。
  • 已解除存储配额：localStorage ~5MB。 本轮已用 IndexedDB 兜底（@@idb:key@@ 占位符协议）， 内存里大图全量、持久层瘦身后基本没有容量问题；导出仍自包含完整 dataURL。
  • 风险单机数据：换浏览器/清缓存会丢数据。已提供 JSON 导出，建议定期备份。
  • 不做真后台推送：需要 Service Worker + Web Push + 推送服务， 纯前端做不到，除非加一个后端。
  • 不做数据考古接入第三方平台的官方接口：点评/小红书/美团无标准导出， 本轮已落地的「通用 CSV/HTML 智能列映射」覆盖了 90% 第三方工具导出场景，够用。
  • 不做多人模式（家庭 / 朋友圈）：需要账号体系与服务端。
  • 不做实体周边（打印相册 / 定制日历）：需要供应链。
