## 怎么打开

| 方式 | 做法 | 能用哪些功能 |
|---|---|---|
| 一 | 双击 `index.html` | 除摄像头、通知、PWA 安装外全部可用 |
| 二（推荐） | 双击 `启动本地服务.bat` | **全部功能**，含实时拍照、通知、装成桌面/主屏应用、离线 |

> `file://` 下浏览器会禁掉摄像头、通知、Service Worker 这三类能力。要用就用方式二。
> 批处理会依次尝试 python / py / node，都没有会提示你回到方式一。

首次打开自动建一对示例用户（小鹿 & 阿柚）并载入 12 条虚构演示旅程，保证一进来就有东西可看、可推荐、可回顾。
想清空换成自己的数据：**我的 → 清空全部数据 → 重新绑定**。

### 装成 App（方式二下）

- **电脑 Chrome / Edge**：地址栏右侧的「安装」图标 → 变成独立桌面窗口
- **手机 Chrome**：菜单 → 「添加到主屏幕」
- **iPhone Safari**：分享 → 「添加到主屏幕」
- 装好后**完全离线可用**（Service Worker 已缓存全部资源）
- 桌面端快捷键：`1`–`5` 切页、`N` 新建、`F` 闪电存档、`Esc` 关弹窗、`?` 看帮助

## 外部服务配置（全部可选，不配也能用）

三样都在 **我的 → 外部服务** 里配。共同原则：**配了就用真的，没配或失败就用本地方案，绝不崩。**

### 🤖 AI 大模型

认 OpenAI 兼容的 `/chat/completions` 协议，所以这些都能直接填：

| 服务商 | Base URL | 模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Moonshot (Kimi) | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 本地 Ollama | `http://localhost:11434/v1` | `qwen2.5:7b` |

设置页有下拉预设，选完自动填端点。点「测试连接」能验证通不通。

接入的两个位置：
- **罗盘文案**：本地模板秒出 → LLM 结果到了替换，并显示「✨ AI 生成」角标
- **唤醒出题 + 成文**：本地题库先出 → LLM 题目到了在**你还没作答时**换掉；成文同理

> ⚠️ 密钥明文存在本机 localStorage，只适合自用。
> 在意安全就把端点换成自建代理（one-api / new-api 之类），**代码一行都不用改**。

### 🌤 真实天气（Open-Meteo）

免费、无需密钥、允许跨域。可选「自动定位」或 17 个内置城市，结果缓存 1 小时。
拿到后罗盘页顶部会显示实况并自动选中对应天气；你手动改天气就会切成手动模式。
网络不通时静默回落到手动选择。

### 🔔 通知提醒

在 **我的 → 外部服务 → 通知提醒** 申请权限后开启三类：

| 提醒 | 时间 | 内容 |
|---|---|---|
| 那年今日 | 每天 08:00 | 「N 年前的今天，你们留下了【魔法暗号】…」 |
| 周末饥饿提醒 | 周五 15–18 点 | 「这周你们只记录了 X 次，罗盘有点饿了🥺」 |
| 草稿唤醒 | 每天 20:00 | 「有 N 段记忆等着复苏」 |

**诚实说明**：没有服务端，浏览器通知只能在**页面开着**时触发。
真正的后台推送需要 Service Worker + Web Push + 推送服务器，那已经不是纯前端能做的事了。
装成 PWA 后至少可以一键从桌面打开，比开浏览器找书签方便。

### Phase 3 四项怎么用

**🌙 深色模式** — 我的 → 外观主题，点一下在「跟随系统 / 浅色 / 深色」之间循环。
不是简单反相，是「夜间暖纸」：深棕底 + 暖米字，保住纸感温度。

**⭐ 星光集** — 我的 → 更多功能 → 星光集。三种看法：
- **瀑布流**：两列错落卡片，适合翻
- **时间轴**：按年份分组，能看清一年的脉络
- **分类**：按纪念日 / 旅行 / 第一次…分组，适合主题回顾
顶部有数量和分类统计，支持搜索。

**✅ 待办** — 我的 → 更多功能 → 待办。紧急程度用星星表示（1–5），
能填预估耗时、截止时间、指派给谁。按紧急度排序，已完成折叠。
PRD 说这是轻量级功能，没做复杂项目管理，故意的。

**💊 时光胶囊** — 我的 → 更多功能 → 时光胶囊。写一封信、定个解锁日期
（有一年后 / 半年后 / 三年后快捷键），到那天首页会提醒，点进去有个开启仪式：
先是密封的 🔒，点「开启」才变成 ✨ 并展开正文。

**📊 年度探险报告** — 我的 → 更多功能 → 年度报告。
核心数字（探险次数 / 有记录的天 / 平均评分 / 人均花费 / 重要时光 / 照片数，还带 **vs 去年**）、
分类分布条、十二月热力、年度最佳、颜色云、偏好标签云、重要时光清单。
点「打印/存 PDF」可以用浏览器的打印功能存成册（CSS 已做打印适配，建议横向无边距）。

**🎄 节日主题推荐** — 罗盘会自动判断当前是否处在节日区间（10 个公历节日），
命中就给契合的目的地加权 +0.4 并显示一张提示卡。
春节、七夕、中秋是农历，公历推算不了，暂未收录。

### 三个新功能怎么用

**📸 实时拍照**
猎人界面点「拍照」或中间大快门 → 全屏取景器：点白圈拍照（可连拍最多 9 张），
右上缩略图可删，左下角图标切前后摄，点「完成(3)」一次性带回。
拍完的照片会按顺序自动填进「全景 / 特写 / 偷拍」的空槽。
闪电存档弹窗里也有「拍照」按钮。
浏览器不支持 `getUserMedia` 时自动降级为调用系统相机（`input capture`）。

**🪏 考古复苏**（入口：首页快捷区 / 旅程列表右上角）
- **账单 CSV**：支付宝、微信导出的 CSV 都能识别，自动抓「商户名 + 日期」
- **粘贴文本**：从账单 App 复制一段粘贴进来，正则提取
- **相册批量**：选一批照片，按拍摄日期分组，每组变成一条草稿并自动取封面

三种来源都会先给一份**可勾选、可改标题的预览**，确认后才写入草稿。
全程只读商户名和日期，**不读金额、不读支付方式、不上传原图**。

**💬 AI 陪聊唤醒**（入口：首页卡片 / 草稿详情页）
草稿超过 3 天且正文少于 20 字时触发。按旅程分类出 5 个「是/否或一两个词」的问题，
依次作答后拼成一段第三人称回忆录，可改可存，状态仍是草稿。

## 与 PRD 的技术性偏离（有意为之）

1. **无后端**：PRD 规划了服务端与多用户体系，MVP 用 localStorage 单机实现。
   双人交互通过「身份切换」在同一台设备上模拟，其余逻辑（双面叙事、双方确认）与 PRD 一致。
2. **文案生成器**：PRD 第九步要求接 LLM。本地版用**模板引擎**生成同风格的亲昵文案，离线可用；
   后续接大模型时只需替换 `Recommend.writeCopy()`。
3. **天气**：PRD 要求调用天气 API。本地版改为用户在罗盘页手动选择（同时用于情景适配加分）。
4. **图片压缩**：PRD 规定 1080px / 85%。因 localStorage 容量有限，降级为 **800px / 68%**；
   闪电存档为 720px / 60%。超出配额时会提示导出备份。
5. **标签黑名单软过滤**：一条低分旅程可能带 6 个通用标签（如「室内」「$$」），全量剔除会清空候选池。
   实现为：地点黑名单硬过滤，标签黑名单在候选 ≥3 条时才生效，否则退化。
6. **勇敢者之选**：使用预置发现库（PRD 允许 MVP 阶段这么做），未接第三方数据。
7. **AI 陪聊唤醒用规则引擎**：PRD 要求调用大模型生成问题。本地版用**分分类的问题库 + 模板合成**，
   离线可用且完全可控；接真模型时替换 `Awaken.bank()`（出题）和 `Awaken.compose()`（成文）即可。
8. **考古复苏不读金额**：PRD 4.1 明确要求。解析阶段会主动过滤余额宝、花呗还款、转账、
   红包等非消费条目，并且**不把金额写进任何字段**。
9. **LLM 只做渐进增强，不做依赖**：界面永远先用本地模板/题库秒渲染，
   LLM 结果到了才替换；请求失败、超时（15s）、返回格式不对一律静默回退。
10. **通知只在页面开着时触发**：无服务端就没有后台推送（PRD 3.4.1 设想的 08:00 推送
    在纯前端下无法保证）。已用 PWA 安装 + 首页横幅做补偿，README 里也写明了。
11. **PWA 需要 http/https**：`file://` 下浏览器禁用 Service Worker 和安装能力，
    所以提供 `启动本地服务.bat`。双击 index.html 时这些能力自动跳过，不影响其它功能。
12. **节日只收公历**：春节 / 七夕 / 中秋是农历，纯公历日期无法推算，未收录（README 已注明）。

## 本地数据的位置

数据存两层：
- **localStorage**（键名 `explorers_compass_v1`）：文本 + 小图 + 索引，~5MB。
- **IndexedDB**（数据库 `explorers-compass`、仓库 `images`）：大图本体（> 48KB 的 dataURL）。
  IndexedDB 不可用时静默回退 localStorage，行为完全一致。

内存里始终持有完整图片（视图 / 导出 / 双面叙事零改动），持久化层用 `@@idb:<key>@@`
占位符协议自动瘦身。

**不上传任何服务器。** 换浏览器 / 清缓存会丢失，请定期用「我的 → 导出全部数据」备份 JSON
（导出已自动还原占位符，文件自包含所有图片）。

- 想让另一半扫码就能用，就部署到你自己买的云服务器 / 静态托管（Vercel / Cloudflare Pages / GitHub Pages 都行）

真机验证步骤：
1. 手机浏览器打开链接 → 分享 → **添加到主屏幕**（iOS Safari）/ **安装应用**（Android Chrome）
2. 装好后从桌面图标进，体验和原生 App 一样（无地址栏、全屏）
3. 切飞行模式 → 打开罗盘 → 仍能正常用，证明 SW 离线缓存生效
4. 摄像头 / 通知 / IndexedDB 三件套在 `https://` 下全部解锁，`file://` 和 `localhost` 都做不到
